From download
to a clearer Mac.

A familiar Mac install. A few minutes to get your bearings.

  1. Move it to Applications.

    Download and open the DMG. Drag Nuke Sweep to the Applications shortcut, then eject the disk image.

  2. Open and take a look.

    Launch Nuke Sweep from Applications. Start with Cleanup for common build-up, or Files to choose a folder.

  3. Measure. Review. Decide.

    Run a scan and inspect the results. Select only what you understand, read the cleanup review, then confirm your action.

Need access to a protected location? macOS may require Full Disk Access. Go to System Settings → Privacy & Security → Full Disk Access and add Nuke Sweep, then quit and reopen it. Grant this only if you need to inspect those locations.

Have another question? ↗
Which Macs can run it?

This download is built for Apple silicon Macs running macOS Sonoma 14 or later. An Intel binary isn’t included. Developers can build the source on a compatible Mac with Xcode and Swift.

Will it delete anything automatically?

No. Nothing is selected for cleanup automatically. You review selections before confirming. Normal cleanup moves files to Trash; emptying Trash and pruning Docker objects are separate permanent actions.

Does it need an account or a subscription?

No account is required to use the app. This release is available as a direct download. There is no subscription flow in Nuke Sweep.

Why hasn’t my free space increased?

Moving files to Trash usually does not free their occupied space. Emptying Trash is a separate permanent action. APFS snapshots, shared extents, and other system activity also affect available space.

How do I add the desktop widget?

Launch the installed app once, then Control-click the desktop → Edit Widgets → search for Nuke Sweep → choose Storage. macOS controls refresh timing; use the menu-bar monitor for live readings.

Where does my scan history go?

Scan history and cleanup receipts stay locally on your Mac under Library/Application Support/Nuke. The original folder name is retained for upgrade compatibility. JSON export happens only when you choose to export.

Is this an early release?

Yes, version 0.8.1 is an early release. Review cleanup carefully and keep backups. An intermittent freeze remains under investigation; reproducible reports and samples help. See the GitHub documentation for current limits.
