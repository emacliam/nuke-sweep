Inside the app

Nuke Sweep inspects local files and system metrics to show storage, process, and cleanup information. Scan history and cleanup receipts are stored locally under ~/Library/Application Support/Nuke. The older folder name is retained so upgrades preserve existing records.

No account is required. This build does not include an analytics or advertising SDK. The app does not upload your scan history to a Nuke Sweep service. Local records may include paths, process names, and CLI output; JSON export happens only when you select an export destination.

Permissions and actions

Folder access and macOS privacy protections still apply. You choose any folder grants, optional notifications, login behavior, and cleanup actions. Full Disk Access must be managed in System Settings. Forgetting a saved folder removes its saved access in the app; it does not change macOS privacy permissions.

Docker inspection uses your installed Docker CLI and selected context, which may point to a local or remote engine. Widgets read system metrics independently and do not read personal scan history.

This website

This is a static site hosted on Vercel. It has no account form, advertising scripts, third-party analytics, or application cookies. Fonts and screenshots are served from the site itself. The hosting provider processes ordinary request information, such as IP addresses and browser details, to serve and protect the website. See Vercel’s privacy policy.

GitHub links take you to GitHub, where its own privacy terms apply. Downloading the app does not subscribe you to email or create an account.
