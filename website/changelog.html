Changelog

0.9.7

  • Trash items can be selected again. One large or unreadable item no longer locks the whole list; it is shown but greyed out.
  • The app follows changes on disk while it is open: Trash, the check's results, an open review, developer caches and worktrees stay current.

0.9.6

  • Very large caches such as Yarn can be reviewed and cleared. Reviews of more than 250,000 files no longer stop part way.
  • One scroll area per screen instead of small boxes inside it.
  • Hover feedback on every button, link and row.

0.9.5

  • Fixes 0.9.4 closing immediately after it opens. If you installed 0.9.4, download 0.9.5 from this site.
  • Much faster scanning: folders are read in bulk across every core, and a repeat check reads only what changed since last time.
  • The cleanup review opens at once and fills as each item is checked. Move what is ready while the rest is checked; Cancel stops it.
  • Package caches such as Yarn are no longer refused because a package ships a file that looks like a key.
  • Clear and Show in Finder on every cache row, a simpler Browse page, Empty Trash in the app, and fixes across every screen.

0.9.4

  • Cleanup opens on an answer: how much you can free without losing anything, with one Free up button. The check runs on its own when there is no recent result.
  • Free up leaves out dependencies from projects you worked on this month and anything used in the last two days.
  • Find your own surplus files: leftover installers, repeat downloads, large old recordings, device backups and stray project builds. Nothing there is ticked for you.
  • Let npm, pnpm, Yarn, Bun, pip, uv, Go and Homebrew clean their own caches, each confirmed with its exact command. Remove clean Git worktrees whose commits are pushed or merged.
  • Empty Trash from inside the app, and see how much space you got back since opening it. Free up is also in the menu bar.
  • Scans run side by side instead of waiting in line, Stop stops at once, and the Move to Trash button stays visible and shows progress.

0.9.3

  • Restart a stopped storage check without carrying over its pending work. Partial scans show a coverage warning, and growth reports compare checks with matching coverage.
  • Developer scans respect ignored locations when finding projects and build folders.
  • Review Docker’s current inventory before running cleanup. The Runtimes tab shows how many simulators use each version and how many are booted.

0.9.2

  • Run Check This Mac from the menu bar and see the result there. Open Cleanup to review individual items.
  • See storage trends, review monthly reports, and share a cleanup summary without file paths.
  • Inspect similar photos and videos, large application data, local snapshots, and developer toolchains.
  • Ignore locations, preview personal files with Quick Look, and try automatic cleanup in dry-run mode. Successful automatic moves can be restored from the alert or receipt.
  • Use the first-run setup to check Full Disk Access and start a scan. The build also includes Terminal and Shortcuts actions for storage checks.

0.9.1

Check for signed updates from Settings → Updates and optionally enable background checks.

0.9.0

  • Check common sources of disk use, including developer storage and personal files you can review.
  • Browse nested folders beside a cleanup assessment. Review which items will move to Trash and restore eligible items from the cleanup receipt.
  • Open Projects, Docker, Devices, and Local models from the Developer tabs. Simulator devices have their own view.
  • See when Trash requires macOS permission and retry the scan after resolving access.
  • Optionally ask an AI provider to explain ambiguous files. Preview the information shared before sending from Browse and cleanup review.

The app preserves existing scan history and receipts when upgrading from 0.8.x. macOS may ask for access again.

0.8.2

Added project build-folder discovery, simulator inspection, and more granular developer cache reviews.
